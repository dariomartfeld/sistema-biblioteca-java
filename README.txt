# Sistema de Biblioteca Pública (Estruturas de Dados em Java)

Aplicação desenvolvida em Java puro (sem uso de Collections) integrando três estruturas de dados implementadas manualmente:

- **Árvore Binária de Busca (ABB):** Gerenciamento do acervo indexado por ISBN (`inserir`, `buscar`, `excluir` e `percursos`).
- **Fila (FIFO):** Controle de reservas de livros emprestados.
- **Pilha (LIFO):** Registro das devoluções do dia para reposição nas prateleiras.
